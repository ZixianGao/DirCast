# DirCast — project page

Static project page for **DirCast: Live Esports Directing and Commentary with a Single Streaming Video-Language Model**.

- `index.html` — the page (no build step)
- `static/video/` — demo video and poster
- `static/img/` — figures cropped from the paper (`extract_figures.py`)
- `static/DirCast.pdf` — the paper

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000.
Publish: make the repository public, then Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
